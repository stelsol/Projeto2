# 🌐 Projeto 2

Projeto desenvolvido com o objetivo de praticar e consolidar conhecimentos em desenvolvimento Front-End, utilizando HTML, Tailwind CSS e Bootstrap Icons para a criação de uma landing page moderna e responsiva.

Teste a aplicação através do link abaixo:

🔗 **Deploy:** https://stelsol.github.io/Projeto2/

## 📌 Status

🚧 Em desenvolvimento — Novas funcionalidades e melhorias serão adicionadas futuramente.

## 🎯 Objetivo do Projeto

Este projeto foi criado como forma de praticar conceitos fundamentais do desenvolvimento web moderno, com foco na construção de interfaces visualmente agradáveis, organizadas e escaláveis.

Durante o desenvolvimento foram explorados conceitos relacionados à estruturação de páginas, estilização com Tailwind CSS e organização de componentes visuais.

## 🚀 Tecnologias Utilizadas

- HTML5
- Tailwind CSS
- Bootstrap Icons

## 📋 Funcionalidades

- Header fixo com menu de navegação
- Banner principal (Hero Section)
- Seção "Quem Somos"
- Seção de Serviços
- Newsletter para captura de e-mails
- Galeria de Portfólio
- Rodapé completo com navegação e redes sociais
- Layout moderno baseado em componentes
- Efeitos de hover e transições

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

- Estruturação semântica com HTML5
- Utilização de utilitários do Tailwind CSS
- Criação de layouts com Flexbox e Grid
- Organização visual de componentes
- Responsividade de interfaces
- Hierarquia visual e experiência do usuário (UX)
- Utilização de bibliotecas externas via CDN
